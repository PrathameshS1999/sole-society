# Sole Society: High Street Clean, teal

The chosen visual direction for the Sole Society demo store.

- `index.html`: open it in a browser. It shows the full store page: header, search suggestions, home, listing with filters and sort, product page with sizes, basket drawer and footer. The spec card on the left lists the palette, type and form. Fonts load from Google Fonts, so stay online.
- `preview-full-page.png`: a screenshot of the same page.

## Palette

| Role | Hex |
| --- | --- |
| Ground | #FFFFFF |
| Tile and panel grey | #EFF4F4 |
| Ink | #0E1A1B |
| Secondary text | #2F3D3E |
| Muted text | #536466 |
| Hairline | #DDE6E6 |
| Action (Add to basket, Checkout, counts, links) | #0E7C7B |
| Action hover | #0A6463 |
| Sale (prices and tag only) | #D7263D |
| Banner block | #DCEBEB |

## Type and form

- **Type:** Instrument Sans 700 for headings and 400–600 for body. Body text is 14.5px, with tabular figures.
- **Corners and borders:** barely rounded (4px) with a pill search field. Cards are borderless and separated by space and grey tiles.
- **Shadow:** only on floating layers (search suggestions and the basket drawer).
- **Density:** tight, with four columns on desktop and two on mobile.

Shoe pictures are placeholders standing in for real product photos. Products, brands and reviews are invented sample data.
